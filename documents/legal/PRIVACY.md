# Privacy Policy (Project-Level)

PopularVote stores only the minimum data required to operate sessions and authenticate users.

## Data We Store
- Supabase user ID (UUID)
- Session metadata (session code, timestamps)
- Anonymous submissions
- Clustered responses
- Upvotes

## Data We Do NOT Store
- Google passwords
- Google OAuth tokens
- Email contents
- Personal profile data beyond what Supabase provides

## Data Processing
Authentication is handled by Google Identity Services.
Database storage is handled by Supabase.

## Data Deletion
Users may request deletion of their stored data by contacting the project maintainers.
