1. Unpackage the project somewhere (e.g. Desktop\PopularVote) and open PowerShell in it
2. Install the backend:   pip install -r src/backend/requirements.txt
3. Install the frontend:  npm install --prefix src/frontend
4. Create src/backend/.env (copy .env.example) and fill in the keys (ask on Slack):

   SUPABASE_URL=
   SUPABASE_SERVICE_ROLE_KEY=
   GEMINI_API_KEY=
   PORT=2167

5. Create src/frontend/.env (copy .env.example):

   VITE_API_URL=http://localhost:2167
   VITE_SITE_URL=http://localhost:6967
   VITE_SUPABASE_URL=
   VITE_SUPABASE_ANON_KEY=

6. Run the Supabase SQL in migration_session_viewers.sql once (unique-device count)
7. From the repo root run: npm run dev
   (starts Flask on :2167 and Vite on :6967 together)

Tests: pip install -r src/backend/requirements-dev.txt, then python -m pytest
